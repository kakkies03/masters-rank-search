# マスターズ順位サーチ

ジャンボウポイント（ナショナル）のマスターズ記録を選手名で検索できるサイトです。
GitHub Pages で公開し、GitHub Actions で毎月2日にデータを自動更新します。

## フォルダ構成

- `index.html` … サイト本体
- `data/` … 記録データ（年ごとのJSONと、名前・所属・大会名の辞書 `dict.json`）
- `scraper/scrape.py` … ジャンボウのサイトからランキングを取得
- `scraper/build.py` … 取得したデータをサイト用の形式に変換
- `.github/workflows/update.yml` … 毎月の自動更新の設定

## 自動更新のしくみ

毎月2日の午前3時（日本時間）に、今年分（1〜3月は前年分も）の
男性・女性 × 長水路・短水路 の4区分を取得し、`data/` を更新して保存します。
保存されると GitHub Pages のサイトも数分で新しいデータに切り替わります。

取得件数がジャンボウ側の対象人数より足りない場合や、前回より大きく減った場合は
取得ミスとみなしてサイトには反映しません（Actions の実行結果が赤くなります）。

## 手動で更新・お試しする

Actions タブ →「ジャンボウデータ更新」→「Run workflow」
- 取得する年：空欄なら今年分。`2025,2026` のように指定も可
- お試し用ページ数：`3` などにすると各区分3ページだけ取得し、サイトには反映しない
  （結果は実行画面下の Artifacts「scrape-result」からダウンロードして確認できます）

データ出典：ジャンボウポイント（https://jambowpoint.jp/）
